# YouTube Video Link Extractor

A modern, dark-themed web application that extracts video titles and links from YouTube channel pages.

## Features

- Bilingual interface (English and Hungarian)
- Automatic processing of YouTube channel video lists
- Extraction and display of video titles and links
- Copy function for easy transfer of results
- Detailed step-by-step guide for using the console method
- Responsive, modern dark theme
- Detailed process status updates

## Usage

1. Open the `index.html` file in a browser
2. Select your preferred language (English or Hungarian) using the language selector in the top-right corner
3. Paste the YouTube channel video list URL (e.g., `https://www.youtube.com/@tvggraphics2423/videos`)
4. Click the "Extract" button
5. The result appears in the text area, from where it can be easily copied

If automatic extraction doesn't work (due to YouTube CORS restrictions), the application provides a detailed guide for using the console method.

## Technical Details

- Pure HTML, CSS, and JavaScript
- CORS proxy for automatic extraction
- Fallback solution with JavaScript console code
- Handling of different YouTube layouts
- Multilingual support with language switching
- Detailed process status updates during extraction

## Installation

No installation required, simply download the project and open the `index.html` file in a browser.

# Youtube linkek lekérése és listázása

Modern, sötét témájú webalkalmazás, amely YouTube csatornák videóinak címeit és linkjeit gyűjti ki.

## Funkciók

- Kétnyelvű felület (angol és magyar)
- YouTube csatorna videólistájának automatikus feldolgozása
- Videócímek és linkek kinyerése és megjelenítése
- Másolás funkció az eredmények egyszerű átviteléhez
- Részletes lépésről lépésre útmutató a konzol módszer használatához
- Reszponzív, modern sötét téma
- Részletes folyamatállapot-frissítések

## Használat

1. Nyisd meg az `index.html` fájlt egy böngészőben
2. Válaszd ki a kívánt nyelvet (angol vagy magyar) a jobb felső sarokban található nyelvválasztóval
3. Illeszd be a YouTube csatorna videólistájának URL-jét (pl. `https://www.youtube.com/@tvggraphics2423/videos`)
4. Kattints a "Kinyerés" gombra
5. Az eredmény megjelenik a szövegmezőben, ahonnan könnyen másolható

Ha az automatikus kinyerés nem működik (YouTube CORS korlátozások miatt), az alkalmazás részletes útmutatót nyújt a konzol módszer használatához.

## Technikai részletek

- Tiszta HTML, CSS és JavaScript
- CORS proxy használata az automatikus kinyeréshez
- Fallback megoldás JavaScript konzol kóddal
- Különböző YouTube elrendezések kezelése
- Többnyelvű támogatás nyelvváltással
- Részletes folyamatállapot-frissítések a kinyerés során

## Telepítés

Nincs szükség telepítésre, egyszerűen töltsd le a projektet és nyisd meg az `index.html` fájlt egy böngészőben.
